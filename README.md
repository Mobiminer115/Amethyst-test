# Amethyst Test — iPad AI IDE

Experimental iPad IDE/AI Agent architecture for Amethyst.

## Planned architecture

- SwiftUI iPad workspace
- Sidebar / Monaco editor / AI Agent panel
- Virtual File System
- OpenAI-compatible tool calling
- `create_file`, `read_file`, `edit_file`
- Diff / Accept / Reject workflow
- GitHub Actions CI

This repository currently contains the architecture bootstrap. The Xcode project and Monaco integration will be added in subsequent commits.
